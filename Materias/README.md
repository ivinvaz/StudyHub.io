# Materias

Este repositório contém os materiais acadêmicos organizados por semestre e disciplina.  
Cada disciplina possui subpastas específicas para facilitar o acesso a **aulas**, **atividades** e **resumos**.

---

## Convenções de organização
- Cada disciplina deve conter **subpastas** para separar os tipos de material:
  - `Atividades/` → exercícios e trabalhos práticos
  - `Aulas/` → slides, PDFs e materiais de apoio
  - `Resumos/` → sínteses e anotações para revisão
- Nomear arquivos de forma clara, usando padrão:  
  `Disciplina_Tipo_Tema.ext` (ex.: `POO_Aulas_Herança.pdf`).

---

## Objetivo
- Facilitar o acesso rápido aos materiais de cada disciplina.  
- Manter a organização por semestre e por tipo de conteúdo.  
- Servir como base de estudo e revisão ao longo do curso.
